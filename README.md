Projeto de estudo de testes unitários com funções de validação de cadastro de usuário, utilizando JavaScript e Jest.

## Sobre o projeto

A atividade exercita a criação de cenários automatizados e a análise de cobertura de código, com foco no comportamento das funções implementadas.

## Objetivos

- Validar o comportamento das funções implementadas em JavaScript.
- Criar cenários para diferentes entradas e resultados esperados.
- Praticar testes de caixa branca e análise de cobertura.

## Tecnologias e ferramentas

- JavaScript
- Node.js e npm
- Jest

## Pré-requisitos

- Node.js e npm instalados.

## Instalação e execução

Instale as dependências e execute os testes:

```bash
npm install
npm test
```

Consulte `package.json` para verificar os scripts disponíveis. A pasta `coverage` pode conter artefatos de cobertura versionados.

## Estrutura do projeto

```text
atividade-exercicio-js/
├── usuario.js
├── usuario.test.js
├── package.json
├── package-lock.json
├── coverage/
└── README.md
```

## Desafios práticos

Definir testes para as funções de usuário, cobrir diferentes caminhos de execução e conferir se os resultados correspondem às regras implementadas.

## Boas práticas

- Separar a implementação do arquivo de testes.
- Manter os cenários executáveis por comando.
- Utilizar a cobertura como apoio à análise, sem tratá-la isoladamente como garantia de qualidade.

## Aprendizados

A atividade permite praticar testes automatizados com Jest, desde a definição dos cenários até a análise da cobertura de código. Também aborda conceitos de caixa branca, observando condições e decisões da implementação para exercitar diferentes caminhos do código.

## Considerações finais

Este projeto é um exercício educacional de testes unitários. Para avaliar sua cobertura e comportamento, execute os testes no ambiente local e consulte os relatórios gerados.
